- **Impact**: Led end-to-end development as Project Admin, coordinating **30+ open-source contributors**.
- **Architecture**: Layered AI pipeline combining STT/TTS, NLP intent extraction, action routing, and tool execution.
- **Stack**: Python, Groq/Cohere LLMs, `asyncio`, Multithreading, Modular System Design.
